## 技术难点与解决方案

### 1. 位置标签乱码问题
**问题**: 模块.js文件编码导致中文显示为乱码
**解决**: 重写整个module.js文件，确保UTF-8编码

### 2. 语法错误（重复声明）
**问题**: generateExcel()函数中有两处`const setCellValue`声明
**解决**: 删除重复的函数定义，只保留一处

### 3. Excel图片嵌入格式
**问题**: 照片文件生成后里面没有图片
**原因**: 使用的twoCellAnchor格式与openpyxl不兼容
**解决**: 
- 改用openpyxl兼容的`oneCellAnchor`格式
- 图片尺寸使用EMU单位：`cx="1714500" cy="1285875"`（约4.8cm x 3.6cm）
- 列索引使用0-base数字（B=1, D=3, F=5, H=7, J=9）

### 4. 模板文件结构
**旧模板** (`capacitor_template.xlsx`, 19282字节)
- 有xl/worksheets/_rels/结构
- VML格式图片（旧格式），不支持新图片

**新模板** (`capacitor_template_v2.xlsx`, 11170字节)
- 无_drawings/目录
- 需要新建drawing相关文件
- 需要添加Content_Types.xml条目
- 需要创建sheet1.xml.rels关系文件

## 关键代码片段

### Drawing XML格式（openpyxl兼容）
```xml
<wsDr xmlns="http://schemas.openxmlformats.org/drawingml/2006/spreadsheetDrawing">
  <oneCellAnchor>
    <from><col>1</col><colOff>0</colOff><row>4</row><rowOff>0</rowOff></from>
    <ext cx="1714500" cy="1285875"/>
    <pic>
      <nvPicPr><cNvPr id="1" name="Photo" descr="Photo"/><cNvPicPr/></nvPicPr>
      <blipFill>
        <a:blip xmlns:r="http://schemas.openxmlformats.org/officeDocument/2006/relationships" cstate="print" r:embed="rId1"/>
        <a:stretch><a:fillRect/></a:stretch>
      </blipFill>
      <spPr><a:prstGeom prst="rect"/></spPr>
    </pic>
    <clientData/>
  </oneCellAnchor>
</wsDr>
```

### 图片关系文件（drawing1.xml.rels）
```xml
<Relationships xmlns="http://schemas.openxmlformats.org/package/2006/relationships">
  <Relationship Id="rId1" Type="...image" Target="/xl/media/photo_1.png"/>
</Relationships>
```

### Content_Types.xml 添加
```xml
<Override PartName="/xl/drawings/drawing1.xml" ContentType="application/vnd.openxmlformats-officedocument.drawing+xml"/>
```

### sheet1.xml.rels 添加
```xml
<Relationship Type="...drawing" Target="/xl/drawings/drawing1.xml" Id="rId1"/>
```
