# 电梯扶手梯故障模块 - 开发记录

**最后更新：2026-04-24 12:41**

## 模块概述
- **模块名称**: 电梯扶手梯故障报告
- **位置**: `E:\openclaw_workspace\property_maintenance_local\frontend\modules\elevator-handrail-fault\`
- **功能**: 月度故障报告 + 月度故障统计表

## 完成功能 ✅

### 月度故障报告 Tab
1. **月份选择** - 年份前后切换 + 月份网格选择
2. **办公楼/商场切换** - 设备列表动态切换
3. **设备网格** - 31天 × 设备矩阵，点击展开故障选择
4. **故障代码选择** - A/B/C/D/E/F/G/H 8种故障类型
5. **每故障详情输入**:
   - 报修时间（时:分）
   - 解困时间（时:分）+ 未困人复选框
   - 到场时间（日 + 时:分）
   - 故障描述
   - 检查结果（新增）
6. **Excel生成** - 办公楼/商场分别生成到 sheet1/sheet2

### 月度故障统计表 Tab
1. **办公楼/商场统计** - 分别写入对应 sheet
2. **故障清单列表** - 按日期降序排列，可展开编辑
3. **时间输入** - 报修/解困/到场时间，检查结果
4. **设备类型统计** - G18(其他设备) / G20(E开头设备)
5. **月份标注** - I2 单元格写入月份

## 数据模型

```javascript
records: { "date_deviceId" -> "A/B/G" }  // 设备故障码
faultDescs: { "date_deviceId_faultCode" -> "描述" }  // 故障描述
faultTimes: {  // 每故障的时间详情
  "date_deviceId_faultCode": {
    reportHour, reportMinute,
    rescueHour, rescueMinute, isNotTrapped,
    arrivalDate, arrivalHour, arrivalMinute,
    inspectionResult
  }
}
```

## 设备划分

| 类型 | 办公楼设备 | 商场设备 |
|------|-----------|----------|
| P开头 | P01, P02 | P1-P17 |
| L开头 | L01-L10 | - |
| S开头 | S01, S02 | - |
| E开头 | E03, E04 | E7-E26 |

## Excel映射

### 故障报告 (elevator_monthly_report.xlsx)
- Sheet1 办公楼: 故障码 → B-P列(设备) × 7-37行(日期)
- Sheet2 商场: P设备 → B-R列, E设备 → B-U列(row 43-73)
- 备注: Sheet1→R列, Sheet2→V列

### 故障统计表 (elevator_monthly_stat.xlsx)
- Sheet1 办公楼, Sheet2 商场
- I2: 月份
- Rows 5-17: 数据行
  - A=日期, B=报修时间, C=设备号, D=故障描述, E=解困时间, F-H=到场时间, I=检查结果, L=故障分类
- G18: P/S/L设备故障数
- G20: E设备故障数
