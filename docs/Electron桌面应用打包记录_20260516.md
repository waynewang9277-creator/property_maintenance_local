# 物业维保APP 开发日志

## 2026-05-16

### Electron 桌面应用打包

#### 成功版本
- **位置**：`D:\electron_build\output\win-unpacked`
- **exe**：直接双击 `物业维保管理系统.exe` 即可运行，无需参数
- **前端代码**：`resources\app\frontend\`（包含 index.html、modules 等）

#### 关键发现
1. **electron-builder 打包时需要 asar 模式**，这样才能把 main.js 和前端代码正确打包进 app.asar，exe 运行时会自动加载
2. **之前失败的版本**：手动复制 electron 目录结构，缺少正确的 asar 打包，导致 exe 无法加载前端页面
3. **正确打包配置**：
   ```json
   {
     "name": "property-maintenance",
     "version": "1.0.0",
     "main": "main.js",
     "scripts": {
       "build": "electron-builder --win"
     },
     "build": {
       "appId": "com.property.maintenance",
       "productName": "物业维保管理系统",
       "directories": { "output": "output" },
       "win": { "target": "dir" },
       "files": ["main.js","preload.js","frontend/**/*"],
       "asar": true
     }
   }
   ```

#### 打包历程
- `build_temp` 目录：被 Python 服务器锁定，npm install EBUSY
- `fresh_build` 目录：npm 安装慢，最终超时
- `D:\electron_build` 目录：手动复制 electron 目录结构，但 exe 无法加载前端（缺 asar）
- `final_build` 目录：同 D:\electron_build 问题
- `clean` 目录：同上
- `output\win-unpacked`：**成功！** asar 打包正确，exe 可直接运行

#### 注意事项
- electron-builder 打包需要从 GitHub 下载 electron zip（约115MB），国内网络慢
- 打包时不能有其他进程占用 node_modules/electron 目录
- 必须使用 asar: true 配置，才能正确打包前端代码

## 当前状态

### 完成的功能模块

#### 强电维保（strong-power）
- battery-test：应急电池放电测试
- generator：发电机组维护性运转记录
- ats：ATS维护保养记录（占位符）
- capacitor-check：电容检查及测温
- busbar-check：供电母排检查及测温
- power-room-monthly：强电间月度巡检
- elevator-escape：电梯逃生门检查
- elevator-handrail-fault：电梯扶手梯故障报告

#### 维保计划模块（5个分类）
- `strong-power-plan`：强电维保计划（有真实任务）
- `comprehensive-plan`：综合维修维保计划（占位符）
- `weak-power-plan`：弱电维保计划（占位符）
- `air-condition-plan`：空调维保计划（占位符）
- `water-drainage-plan`：给排水维保计划（占位符）

每个计划模块功能：
- 日历视图：显示当月日期，点击可选中日期查看计划
- 任务列表：显示当月已安排的日期数量
- 日期分配：点击"分配日期"按钮弹出日历选择
- 动态标签：有任务的日期会显示彩色任务标签
- 矩形色标：当日、选中日期改为矩形圆角（8px），非圆形
